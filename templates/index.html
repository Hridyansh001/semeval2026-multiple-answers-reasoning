Principled Imbalance Handling & Evaluation Integrity Rationale

1. Dev Data Strict Isolation

Development data is strictly quarantined from any balancing or re-sampling to preserve real-world prior class distributions.

2. Loss-Level Class Weighting

BCEWithLogitsLoss utilizes exact per-option positive weight vector pos_weight_k = (N_total - N_pos_k) / N_pos_k.

3. Multi-Hot Target Representation

Formulated as continuous multi-hot float vectors [1.0, 0.0, 1.0, 0.0] allowing multiple non-exclusive causal answers.

Multi-Answer ALBERT Pipeline Architecture

Input Paired Premise:
Sentence 1: [EVENT] {target_event} [DOCUMENTS] {formatted_context_documents}
Sentence 2: [CAUSE OPTION] {option_k} (for k in [A, B, C, D])
▼ AutoTokenizer(max_length=256, padding='max_length', truncation=True)
ALBERT Encoder & Pooling:
AlbertForMultipleChoice forward pass -> Cross-choice logits (Shape: [Batch, 4])
▼ nn.BCEWithLogitsLoss(pos_weight=pos_weight_tensor)
Multi-Answer Sigmoid Thresholding:
P(k) = σ(logit_k) ≥ threshold (default 0.50) -> Multi-Hot Decision Vector
